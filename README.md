# Vaya Tours & Travels

Premium tours & travels website (HTML, CSS, JavaScript, Bootstrap 4). No build step needed.

## Run in VS Code
1. Unzip the folder and open it in VS Code (File > Open Folder).
2. Install the **Live Server** extension (Ritwick Dey).
3. Right-click `index.html` > **Open with Live Server**.

Alternative: open `index.html` directly in a browser, or run `python -m http.server 8000` in this folder and visit http://localhost:8000

An internet connection is needed for Google Fonts and the YouTube video.

## Pages
`index.html` (Home), `services.html`, `about.html`, `contact.html`

## Where to edit
- Text and sections: the four `.html` files
- Premium styling, 3D effects, animations: `css/vaya.css`
- Interactions (booking form, countdown, coupon copy, tilt effects): `js/vaya.js`
- Original template styles: `css/style.css` (avoid editing; override in `vaya.css`)
- Images: `images/`

## Sample content to replace
Prices, offer codes, reviews, ratings, sale end date (in `js/vaya.js`), address, phone and email are placeholders.
The contact and newsletter forms show a message only; connect a backend or form service before launch.
